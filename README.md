# Attack Surface Intelligence

System do cyklicznego, bezpiecznego skanowania rozległych sieci: wykrywanie hostów i usług, fingerprinting HTTP/TLS i technologii, własne sygnatury, porównywanie przebiegów skanu, RBAC, szyfrowanie danych w spoczynku i eksport do DefectDojo.

> README produktu: instalacja (docker compose), konfiguracja, role, format sygnatur i integracja z DefectDojo zostaną uzupełnione wraz z implementacją.
